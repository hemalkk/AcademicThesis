# Reproducibility Guide

## Primary Notebook

The main notebook for reproducing the final baseline experiment is:

```text
notebooks/Android Malware Final Code.ipynb
```

Earlier notebooks in the `notebooks/` directory are retained as exploratory or supporting work and may use different preprocessing, evaluation, or visualisation workflows.

## Environment Setup

Use Python 3 and install the repository dependencies:

```bash
pip install -r requirements.txt
```

The main packages are:

- numpy
- pandas
- scikit-learn
- matplotlib
- seaborn
- lazypredict

## Dataset

The dataset is expected at:

```text
data/Drebin Dataset.csv
```

The notebook uses a Drebin-derived static Android dataset containing permission and API-call-related features.

## Reproducing Results

1. Clone or download the repository.
2. Install the requirements.
3. Open `notebooks/Android Malware Final Code.ipynb` in Google Colab or Jupyter Notebook.
4. Confirm the dataset path points to `data/Drebin Dataset.csv`.
5. Run the notebook cells sequentially from top to bottom.
6. Review the generated tables and figures for cross-validation, held-out test evaluation, ROC curves, confusion matrices, feature importance, PCA, and exploratory LazyPredict screening.

## Experiment Protocol

The final experiment follows this protocol:

- One record with a missing target label is removed.
- Five `?` values in `TelephonyManager.getSimCountryIso` are converted to numeric form before modelling.
- Features are derived from static Android permissions and API-call-related indicators.
- Data are split using a stratified 80:20 train-test split with random seed 42.
- Five-fold stratified cross-validation is applied on the training data.
- Random Forest, SVM, Decision Tree, and KNN are evaluated.
- StandardScaler is used for SVM and KNN pipelines.
- Performance metrics include Accuracy, weighted Precision, weighted Recall, weighted F1-score, and ROC-AUC.

## Expected Results

Results may vary slightly due to software versions, runtime environment, or model implementation details. The expected overall ranking is:

1. Random Forest
2. SVM
3. Decision Tree
4. KNN

The reported results apply to this processed Drebin-derived dataset and should be interpreted as an offline static-analysis baseline evaluation.

## Output Files

When executed, the final notebook may create generated figures and result files in:

```text
final_outputs/
```

This folder is excluded through `.gitignore` because its contents can be regenerated by running the notebook.

## Limitations

This repository does not provide a deployed Android application, real-time malware detection, runtime behavioural analysis, or measurements of latency, battery consumption, memory use, or model size.

The experiment is based on a Drebin-derived dataset and does not establish generalisation to current Android malware or operational environments.
